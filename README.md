# Taula periòdica · Joc

App web (un sol fitxer, sense dependències) per practicar la taula periòdica.

L'app il·lumina una casella a l'atzar i has d'omplir:

- **Símbol**
- **+/−**: càrrega de l'ió / estat d'oxidació habitual (accepta qualsevol dels valors habituals de l'element)
- **Nom** en català (normativa de l'IEC; accepta sense accents ni punt volat)
- **Protons** (nombre atòmic)

Les caselles s'acoloreixen segons el resultat (al primer intent / amb errors / solució) i les que falles tornen a sortir al final. Es pot limitar l'abast (36 o 54 primers, sense lantànids/actínids, només grups principals).

## Ús

Obre `index.html` al navegador.
